# V3.1.19 — Simulador mais claro

Atualização focada na compreensão das perguntas da calculadora de participação.

## Mudanças

- perguntas reescritas em linguagem mais direta;
- explicação expansível “O que significa?” em cada campo;
- exemplos práticos para núcleos operacionais, operações simultâneas e unidades ativas;
- explicação individual dos quatro níveis de integração;
- regras práticas para ajudar a empresa a escolher a opção correta;
- novo CSS específico da calculadora para organizar os blocos de ajuda em desktop e mobile;
- versão atualizada para `3.1.19`.

## Preservado

Os IDs dos campos, os valores de cada opção e a lógica de cálculo do simulador não foram alterados. Também não houve mudança em adesão, mensalidades, APIs, banco, formulários ou infraestrutura.
