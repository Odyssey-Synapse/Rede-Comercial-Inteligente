# V3.1.17 — Uai Perto

Atualização de identidade pública da Rede Comercial Inteligente de Uberaba.

## Destaques

- identidade pública alterada para **Uai Perto**;
- assinatura **Uberaba mais perto de você.**;
- paleta oficial Hunter Green, Sunflower, Rust e Pristine;
- logotipo horizontal e símbolo oficial adicionados como assets web;
- favicon e metadados passam a usar Uai Perto no navegador;
- identidade visual aplicada sem alterar o núcleo funcional existente;
- versão do projeto atualizada de `3.1.16` para `3.1.17`.

Não há alterações no modelo dos 54 parceiros iniciais, calculadora, valores, regras comerciais, formulários, APIs, banco, autenticação, Turnstile, integrações, rotas ou configuração de produção.
